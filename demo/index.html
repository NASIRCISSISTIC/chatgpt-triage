Triage: live demo

This page stands in for chatgpt.com, with a made-up account of about 280 chats. Triage runs exactly as it would there, but every request is answered inside this page. Nothing touches a real account.

Try it: move with ↑ ↓, press D to queue a delete, A to archive, R to rename, then Run Queue. Waits run faster than the real thing so the demo doesn't take all day. Turn on simulated limits to watch Triage handle ChatGPT's "Too many requests".
